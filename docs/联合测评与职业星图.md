# 联合测评与职业星图

主流程：个人画像 → 多智能体联合测评 → 职业星图 → 行动计划 / 智能体咨询。

## 使用

1. 登录后进入 `/multi-agent`，补充实际目标并开始联合测评。
2. 六个智能体完成且报告已保存后，点击「下一步：绘制职业星图」。
3. 星图读取所选报告，提取职业方向、进阶/迁移路线、能力差距和行动建议。
4. 点击图中节点或下方分支按钮查看测评原文依据，再进入智能体咨询或成长计划。

能力补充测评保留为辅助功能，不替代完整联合测评。部分完成的报告不能生成星图。

## 数据与安全

- `/api/report-graph/reports` 只列出当前登录用户的完整联合测评。
- GET `/api/report-graph/{id}` 读取该报告已保存的星图；POST 生成并保存。
- 服务端检查所有权、六段内容、职业分支和逐字引用依据；无法提取时明确失败，不渲染孤立中心节点冒充成果。
- 星图存放在原报告 JSON 的 `careerGraph` 字段，保留原报告正文。使用 JSON 比较做并发更新保护。
- 已保存的星图不重复调用模型。用户刷新、退出再登录后仍能查看。
- 需要换一版时点「↻ 重新生成星图」：POST `{id}?force=true` 绕过缓存重新提取并覆盖，覆盖同样受 JSON 并发保护。
- 分支的 `skills` / `actions` 会在服务端规范化：去首尾空白、剔除空白项、最多 3 条；两者同时为空的分支视为无效。
- ECharts 节点使用稳定 ID，重复的岗位/技能名称不会导致连线丢失。

## 设计参考

阅读参考：[claude-directory 的 Lumina Minimalist Modern 提示词](https://github.com/pulkitxm/claude-directory/blob/main/ui-design/lumina-minimalist-modern/prompt.md)。采用清晰层级、留白、蓝色主操作、局部深色图表、响应式布局和可见焦点；用现有 Vue / ECharts 实现，没有引入其 React 动画依赖。

共享样式在 `前端/src/styles/careerWorkbench.css`；图数据转换在 `GraphView.vue` 的 `mapBranches`（分支只展示前 4 个，其余在下方分支列表切换）。文件统一 UTF-8，编辑器请保持 UTF-8。
