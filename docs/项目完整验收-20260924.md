## 本轮修复

### 岗位分页失效

复现：`GET /api/job-info/page?current=1&size=5` 返回 9,958 条，`total=0`，说明分页对象未转为数据库分页。

修复：引入同版本 `mybatis-plus-jsqlparser`，注册 MySQL 分页拦截器、限制每页最多 100 条，岗位列表添加 ID 作为同时间戳排序的第二依据。参考 [MyBatis-Plus 官方分页说明](https://baomidou.com/plugins/pagination/)，3.5.9 起分页解析依赖需单独引入。

验证：真实接口每页 5 条、总数 9,958、相邻两页 ID 不重叠；集成测试覆盖总数、页数、越界空页、非法页参数和上限。

### 数据库启动保护

原脚本遇到表数量小于阈值即执行含 DROP 的全量结构脚本，可能覆盖一个已有但不完整的库；迁移失败也只告警。

现在仅空库或显式强制初始化可执行全量结构脚本；已有但不完整的库直接停止，缺失 / 失败的迁移阻止后端启动。保留原 31 表兼容阈值，没有贸然改成 40 触发旧库重建。增加 5 项无数据库回归，并接入 CI。

### 页面和部署说明

- 移除个人中心不存在的上传接口及“失败后模拟成功”逻辑，改为禁用并明确“上传解析待接入”。
- 导师大屏改为明确展示静态示例数据，不再宣称实时监控学生。
- 移除登录页不存在的 `/your-image-name.png` 引用，构建不再出现该资源警告。
- Nginx 静态目录改为仓库真实的 `前端/dist`，补 MIME 类型文件和日志目录；更新部署说明。
- 更新 `.env.example` 表数说明，增加可复用的后端测试入口和全站验收脚本。
