## 22:00 补充：核对 `.env.example` 指向的地址形式

按实际应用 ID 替换 `<appid>` 后，地址为 `https://202609APqqd122487260.tboxpro.cn`。实测结果如下：

| 地址 / 鉴权方式 | `/api/health` 结果 |
|---|---|
| 实际 `.env` 的 `…-coding.tboxpro.cn` | 503，`Agent not found` |

## 结论

当前 503 的直接原因已定位到百宝箱入口网关：它找不到 URL 指定的应用，返回：

```text
HTTP 503
Server: Spanner
Agent not found: 202609apqqd122487260
```

本地配置基址是 `https://202609APqqd122487260-coding.tboxpro.cn`，与当前仓库文档一致；`.env` 的应用 ID 与该主机名一致。仓库[接入说明](../百宝箱/接口清单与接入说明.md)明确写明这是预览地址，正式发布后地址可能更新，正确来源是平台 `APP_API_URL`。

**能够确认：请求在网关定位应用这一步失败。尚不能确认：应用被停止 / 移除、预览入口失效、发布地址变化，还是平台路由异常。** 这些需要查看对应应用的控制台状态及平台日志，不能仅凭 503 判定应用已被删除。
