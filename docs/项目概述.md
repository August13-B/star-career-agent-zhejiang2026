# 星职 · AI 职业导航与终身学习伙伴系统

> **项目概述文档**（仓库 README 用）——基于"基于多智能体与多模态 RAG 引擎的智能引航系统"（国赛 A13 国三作品）迁移至省赛 A02 赛题
> 更新时间：2026-08-15

## 一、项目简介

星职（StarCareer）是一套面向未来工作的 **AI 职业导航与终身学习伙伴系统**。系统以职业知识库为底座、以大模型智能体为核心，融合**多智能体协同（MOE）**与**多模态 RAG 检索增强**技术，围绕"感知 → 认知 → 决策 → 生成 → 执行 → 反馈"全技术闭环，为高校学生及职场新人提供个性化职业规划、人岗精准匹配、成长路径拆解与长期陪伴服务。

系统前身《基于 AI 的大学生职业规划智能体》（国赛 A13，获全国三等奖），现按省赛 A02 赛题要求（蚂蚁百宝箱企业版平台、MCP 协议、多端发布、AI 伦理设计）进行适配演进。

### 核心价值

- **懂学生**：10 维能力画像 + 动态职业画像，量化自我认知
- **懂岗位**：10000+ 真实岗位数据构建职业认知知识底座
- **懂成长**：垂直晋升图谱 + 横向换岗图谱 + 3-5 年职业路径
- **懂陪伴**：情绪感知、目标监督激励、计划动态调整（开发中）

## 五、主要功能

1. **智能体对话**：RAG 增强的职业规划问答，SSE 流式输出 + 打字机体验
2. **职业星图**：垂直晋升链路 + 横向换岗路径的可视化宇宙星图
3. **AI 能力测评**：多维能力量化评估（能力测评/评分历史）
4. **人岗匹配**：10 维双向画像匹配，输出匹配度与差距分析
5. **生涯报告**：职业探索→目标设定→路径规划→行动计划，支持润色/编辑/导出
6. **多智能体中控（开发中）**：MOE 专家混合协同，当前为演示原型
7. **学生就业大盘（B 端）**：班级/院系就业数据看板（当前为静态展示）
8. **岗位管理（B 端）**：岗位数据维护、AI 自动分析入库

## 六、本地启动指引（概要）

| 模块 | 端口 | 启动方式 | 依赖 |
|---|---|---|---|
| 后端1 | 8080 | `mvnw spring-boot:run` | MySQL（youthpath）、Redis |
| 后端2 | 8082 | `mvnw spring-boot:run` | MySQL（youthpath） |
| AI 服务 | 8081 | `mvnw spring-boot:run` | PostgreSQL（langchain_rag）、DashScope API Key |
| 前端 | 5173 | `npm install && npm run dev` | 后端隧道地址（见 `src/config/api.js`） |

> ⚠️ 数据库初始化：导入 `code/数据库/数据库结构.sql`；AI 服务需在 `application.yml` 配置 DashScope API Key（已脱敏为占位符）；大文件（向量库 JSON、知识库 CSV）不随仓库分发，需从网盘获取。
