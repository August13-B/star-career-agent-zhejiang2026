## 一、提示词全文（直接整段复制粘贴给创建助手）

```
请更新当前应用里三个「职场训练接口」的**提问纪律**（重点是"模拟面试"），只改系统提示词，
不要改接口路径与出入参，不要动其它链路。

【要解决的问题】
1. 现在的面试题和追问几乎都是开放式的（例如"选一个技术点讲讲"），**没有可判对错的技术题**，
   不符合真实技术面试——真实面试会考查有明确答案的知识点。
2. 题目里塞进了**提示与答题要求**，例如：
   - "请按下面三个点展开：你的角色 / 你负责的部分 / 遇到的最大问题 / 解决方式"
   - "请从以下角度回答…""提示：…""建议…"
   这些都不能出现在**问题**里。

【三条硬要求】

■ 要求 1：整场至少一半题目必须是「有明确答案的技术题」
- 技术题要围绕**该岗位的关键技能与职责**（任务指令里会给出：目标岗位、关键技能、职责描述）出题，
  考查：该技术的**原理/机制**、关键参数或边界、**"某种情形下应该怎么做"的正确做法**、
  以及常见错误的判断（例如"这样做会发生什么、为什么"）。
- 这类题必须**存在客观正确答案**，作答后能按事实判定对错；不能是"你怎么想都行"的开放题。
- 其余题目可以是**经历题 / 情境题**（开放式），但也不得带提示与答题结构。

■ 要求 2：**问题里不得出现任何提示、要求或脚手架**
禁止出现在提问中的内容（列全，务必逐条遵守）：
1. "请按下面三点/以下角度展开回答"
2. "提示：…""建议…""可以参考…""回答时请包含…"
3. 要点清单、答题结构模板、分点框架（如"1. 用途 2. 职责 3. 难点 4. 结果"）
4. 评分标准、考察点说明、维度名称、权重
5. 示例答案、参考答案、正确思路
6. 括号里的教学式说明（如"（考察你的取舍能力）"）
7. "没有经历也可以说明，然后用假设案例练习"之类的**答题指导**（这类话只在收尾或用户主动求助时讲）

提问要像真实面试官：**一两句话直接问**，最多补一句必要背景（如"假设线上出现 X 现象"）。
**允许出现的**：情境背景本身（"假设…，你会怎么做？"）、以及必要的岗位信息（"这个岗位要做 X"）。

■ 要求 3：追问要基于作答、且同样不带提示
- 引用其原话追问**细节 / 边界 / 代价 / 替代方案**，例如：
  "你刚才提到用 A 方案，为什么不用 B？""如果流量翻十倍会怎样？""这个改法的代价是什么？"
- **不得**在追问里给思路提示或结构；同一道题最多追问 2 轮（任务指令会写明剩余次数）。

【难度语义（只影响"是否可在用户求助后给提示"）】
- `standard`：全程不给任何提示。
- `entry`：仅当用户**明确表示"不会/没做过"并请求帮助**时，给**一句话方向性提示**；
  仍不得把结构、要点清单或答案写进题目。

【评分阶段（evaluate）才允许出现提示与标准】
- 只有在 `mode=evaluate` 时，才允许出现评分维度、rubric、评分依据、改进建议、参考答案对照。
- 评分时**必须对技术题逐题判对错**：明确说明"答对了什么、错在哪里、正确说法是什么"，
  并在对应维度上体现（技术题答错不能因为表达流畅而给高分）。
- `comment` 与 `suggestions` 中**不要使用英文双引号**（如需强调请用「」）——裸引号会破坏 JSON。

【输出格式不变】
- `mode=ask`：只输出本阶段的提问（沿用既有 JSON 形制或纯文本），不含任何提示与评分。
- `mode=evaluate`：只输出既有评分结构（training_evaluation / ability_evaluation），不输出 total。

【交付要求】
① 给出更新后的三个训练接口系统提示词全文（重点是模拟面试）
② 明确说明"提问 vs 评分"两阶段各自允许出现的内容边界
③ 说明如何保证与对话链路、报告链路、能力补充测评接口互不影响
④ 改完是否需要重新发布才生效
```

### 平台侧（Node）遗留项：评分提取层建议补「裸引号修复」

- 现状：`server/src/training/training-service.ts:61` 只做**剥围栏/信封 + 截取**，不解析也不修 JSON
- 影响：目前裸引号 JSON 由 **Java 后端 `JsonRepair`** 兜底（**已用真实坏 payload 验证可救回**），所以不补也不丢分；
  但补上能更早归一，**能力补充测评**那条链路同理受益
- 建议实现（与 Java 版同算法，可直接粘贴）：

```ts
/** 仅在 JSON.parse 失败后调用：转义字符串值里未转义的裸双引号（模型把强调词加引号时会出现） */
export function repairUnescapedQuotes(text: string): string {
  const isTerminator = (from: number): boolean => {
    let i = from
    while (i < text.length && /\s/.test(text[i])) i++
    if (i >= text.length) return true
    return ',}]:'.includes(text[i])
  }
  let out = ''
  let inString = false
  for (let i = 0; i < text.length; i++) {
    const c = text[i]
    if (!inString) {
      out += c
      if (c === '"') inString = true
      continue
    }
    if (c === '\\') {
      out += c
      if (i + 1 < text.length) out += text[++i]
      continue
    }
    if (c === '"') {
      if (isTerminator(i + 1)) { out += c; inString = false } else { out += '\\"' }
      continue
    }
    out += c
  }
  return out
}

// 用法：先严格解析，失败再修复重试；仍失败则把原文前 500 字打日志
export function parseLenientJson(text: string): unknown {
  try {
    return JSON.parse(text)
  } catch (strict) {
    try {
      return JSON.parse(repairUnescapedQuotes(text))
    } catch {
      console.error('评分 JSON 解析失败（修复后仍失败）:', strict, text.slice(0, 500))
      throw strict
    }
  }
}
```
