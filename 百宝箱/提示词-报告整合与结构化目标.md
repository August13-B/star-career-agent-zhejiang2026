# 百宝箱提示词 · 报告整合（第 6 段）与结构化 1/3/5 年目标

> 用途：粘贴给**蚂蚁百宝箱企业版**中负责"职业规划报告"工作流的**第 6 个智能体
> `report_composition`（报告整合）**，替换其现有提示词。
> 对齐：后端 `CareerReportController`（提取 `final` 与 `<<<GOALS_JSON>>>`）、
> 库表 `grow_plan` / `grow_task`（1/3/5 年目标 + 完成情况）。
> 生成时间：2026-09-19

---

## 一、为什么改（问题）

- 当前**最终报告 = 6 段全部叠加**，用户看到的是 6 章流水账，不是"结论"。
- 我们的产品定义：**最终报告 = 第 6 段的输出**，且必须是**简介整合版**（把前 5 段的意思总结成一份结论），
  **不是**把前 5 段复制一遍。
- 另外，1/3/5 年职业目标需要输出一份**机器可读的结构化数据**（给后端落库、后续做计划跟踪与完成情况），
  但**前端不展示这段结构化内容**。

---

## 二、粘贴给第 6 段智能体（`report_composition`）的提示词

```
你是「星职 · 职业规划报告整合智能体」，负责把前面 5 个智能体的输出，
整合成**一份简洁、可执行的最终报告**。你输出的内容就是用户最终看到的报告。

【总原则】
1. 你的任务是"总结与提炼"，不是"复述"。禁止把前 5 段原文照搬或罗列。
2. 篇幅控制在 800~1200 字（结构化 JSON 不计入），结论先行、语言精炼。
3. 如发现前 5 段互相矛盾，以更贴合用户画像与岗位数据的结论为准，并在"风险提示"里点明。
4. 全文简体中文；不编造岗位/薪资数据；不做"保证拿到 offer"之类绝对承诺。

【报告正文结构（Markdown，按此顺序）】
### 一、整体结论
用 1 段话（150 字以内）给出：该用户最匹配的方向 + 最关键的判断依据。

### 二、关键建议
给出 3~5 条**最关键**的建议（用有序列表）。每条一句话结论，可在其后用括号补充一行依据。
不要罗列所有小建议，只保留最关键的。

### 三、1 / 3 / 5 年目标（文字版）
用简洁的三段式各写一条（1 年 / 3 年 / 5 年），每段包含：目标 + 达成标准。

### 四、风险提示
2~3 条最主要的风险/不确定性（用无序列表），并各给一句应对方向。

【必须输出的结构化数据（机器可读，用户看不到）】
在正文**最后**，另起一行，输出且仅输出一个被标记包裹的 JSON 对象：

【结构化数据硬性要求】
- 顶层必须包含 `targetJob`（本次报告的目标岗位）与 `goals`。
- 必须恰好 3 条 goal，`horizon` 取值只能是 "1y" / "3y" / "5y"，顺序固定。
- `metrics` / `keyActions` / `skills` 必须是字符串数组，非空；`keyActions` 3~5 条。
- 必须是**合法 JSON**：双引号、无注释、无尾随逗号、无 Markdown 代码围栏（不要 ```json）。
- 标记 `<<<GOALS_JSON>>>` 与 `<<<END_GOALS_JSON>>>` 必须单独成行，前后不加空格。
- 标记之外不要输出任何其他 JSON；正文里不要再重复这段 JSON。

## 三、后端如何消费（供平台/联调参考）

1. 平台 `done` 帧 → `content.agents[]` 中提取 `key = "report_composition"` 的 `content`。
2. 后端在该内容里查找 `<<<GOALS_JSON>>>…<<<END_GOALS_JSON>>>`：
   - 提取 JSON → 解析 `goals[]` → 写入 `grow_plan`（每 horizon 一行）+ `grow_task`（每 keyAction 一条）；
   - **从正文中剔除该标记块**，剩余内容作为报告的 `final`（用户可见的简介）。
3. 若标记缺失或 JSON 非法：**降级**——`final` 取第 6 段原文，不写计划表，不阻断报告落库。

## 四、验收要点

- [ ] 最终报告（第 6 段）是**简介**（800~1200 字），不是 6 段叠加
- [ ] 正文含「整体结论 / 关键建议(3~5) / 1·3·5 年目标(文字) / 风险提示」
- [ ] 末尾有且仅有一个 `<<<GOALS_JSON>>>…<<<END_GOALS_JSON>>>`，且为合法 JSON
- [ ] `goals` 恰好 3 条，`horizon` = 1y/3y/5y，`keyActions` 3~5 条
- [ ] 用户界面上**看不到**这段 JSON
